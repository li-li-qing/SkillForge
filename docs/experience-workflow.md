# 主动经验沉淀与共享源维护

用户维护一份SkillForge总目录，由多个Agent共用。个人习惯跨项目延续；领域知识按适用范围存放。讨论形成明确决定或验证产生可复用经验时，主动及时记录，不等用户再说“记下来”。实际写入仍需已确认共享根、权限和安全的并发方式；不可访问时说明未落盘。

## 权威落点

- 个人协作约定：[用户习惯](../skills/skillforge-orchestrator/references/user-workstyle.md)。
- 记录、晋升与冲突：[经验维护](../skills/skillforge-experience-maintenance/SKILL.md)。
- 高成本方向先证据后实现：[工程前置验证](../skills/skillforge-engineering-preflight/SKILL.md)。
- 项目专属路径、版本、架构决定和进度：当前项目资料；不误写成跨项目规则。

## 最小闭环

读取既有经验 → 记录条件/证据 → 判断事实、偏好、假设与临时处理 → 无冲突且证据充分才正式更新 → 检查引用/验证 → 交付实际更新状态。

失败也记录；不确定结论留候选。多人写入先取得真实锁/版本条件，在锁内重核最新内容，拒绝旧基线覆盖。没有保护能力则只留独立候选。冲突不阻塞其他目标，未回复不是批准。

可选本地工具只保护协作写入和撤回，不做语义审查，不是后台同步。工具、记录格式与限制以经验维护技能为单一说明来源；避免在此复制第二套协议。
