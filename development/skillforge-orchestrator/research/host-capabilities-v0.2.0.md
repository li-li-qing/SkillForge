# 宿主能力适配

先记录当前实际能力：能否读取目录/文件、原生发现/调用技能、执行 shell、写文件、获取上下文计量、执行原生压缩、启动隔离 Agent。未知填 unknown，不因产品名称默认具备。

## 原生支持 Skills

使用宿主支持的显式入口与真实技能清单。读取技能正文和执行它的脚本是两件事；宿主工具会自动执行内容时，准备阶段不要用这种调用方式冒充只读。宿主禁止的技能不得借手工读取绕过。

Codex 可按官方文档显式提及技能；本包可选 agents/openai.yaml 把隐式调用关闭，使入口更适合作为用户指定起点。该元数据不影响其他宿主，不是权限拦截器，也不会自动安装叶子技能。[官方说明](https://developers.openai.com/codex/skills)。

Claude Code 的显式 Skill 命令与原生上下文命令不是同一种机制；官方 Skills 文档明确原生 compact 命令不可通过普通 Skill tool 调用。不要把聊天命令交给 shell。本版不改用户的宿主设置或 hook。[官方说明](https://code.claude.com/docs/en/skills)。

## 只能读文件

用户提供入口 SKILL.md 的实际位置；读取本文件后，仅在已知技能根或当前可见资源中查找候选。路径是可读证据，不应谎称获得原生 Skill 调用事件。跨目录技能不作为本包的硬链接依赖。

## 只能粘贴文本

只能依据提供的正文、项目片段和元数据判断；不能声称扫描项目/执行验证/调用未提供的技能。资料不足时给条件性简报，写明需要补充的最少资料。无 Python 时索引脚本不是必需项，手动读取可见元数据即可。

## 权限与安全

Agent Skills 标准中的 allowed-tools 为实验性宿主相关字段；本包不预授予工具。准备/确认流程是语言层规则，强制只读要使用宿主已有的只读/计划权限设置，并实测其行为。本包不改变权限，也不承诺跨宿主强制门禁。[格式规范](https://agentskills.io/specification)。
