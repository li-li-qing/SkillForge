# 蓝图接口与教程交接

用于 LGF 接口审查、已授权的危险节点清理和新手教程维护。来自旧 `lgf-development-auditor` 的 blueprint-api/documentation 参考；2026-09-15 与新库对比后补入遗漏的交接细节。本页是维护检查，不声称当前插件有同名缺陷或接口。

## 接口分层与失败反馈

- 玩家动作经现有 Request/Agent；内部 Server RPC 不因蓝图方便而公开。真正需要通用 Authority 扩展时，核对运行期权威校验，不能把 `BlueprintAuthorityOnly` 元数据当作 C++ 安全校验或跨网传输。
- `BlueprintPure` 留给廉价、确定、无副作用的查询。全数组快照、遍历/分配或刷新缓存采用明确执行入口；UI 按初始化与变化事件消费，避免隐式重复求值。
- 正常无效输入、空目标、容量不足返回可识别失败；`ensure` 用于程序员不变量，不把普通用户拒绝刷成断言。
- 提交、最终业务结果和本地预测反馈分别说明。异步并发操作用当前真实 RequestId/Handle 关联；超时不证明服务器没执行，迟到结果、重复请求、取消与页面关闭按协议收敛。
- 蓝图通知用可绑定的事件和只读值/稳定身份；初次绑定同时解决当前快照与后续通知。按来源协议订阅后读快照，或用版本检查补读，避免二者之间漏更新；重复通知需安全。UI 不等待“下一次修改”才显示已有物品。

## 删除与改签名的交接单

先搜索声明、实现、配置、文档、C++ 和可检查资产引用；无法读图的资产明确列为待迁移。用户已授权破坏性 API 清理时直接完成范围内删除，不为了隐藏 Blueprint 断线保留危险 deprecated wrapper。

每个实际变更至少交付：

| 项目 | 需要交代的内容 |
|---|---|
| 旧入口定位 | 所属类型、完整节点名、原 Category；能检查时给受影响资产/图位置 |
| 替代入口 | 真实存在的节点、Target 对象来源；没有替代能力则明确缺口 |
| 引脚迁移 | 旧→新参数、类型/默认值、执行线、返回分支；不要只说“改用 Request” |
| 结果迁移 | 同步成功线如何拆为提交反馈与最终事件；关联身份怎样传递 |
| 序列化影响 | Struct 字段/Enum 数值、Make/Break、保存结构及资产重存的影响；按实际变更检查 |
| 验证范围 | UHT/构建、受影响蓝图编译/保存/重载、成功/拒绝/重复及相关网络路径分别记录 |

Category 沿用模块现有命名空间，不混入另一套前缀；全局改分类属于独立范围。复杂节点 ToolTip 说明调用角色、所有权、返回的提交/完成语义、服务器再校验内容、最终结果入口及显著遍历/加载成本。

## 教程按依赖顺序可执行

先列最小依赖链：父类/插件 → Tag/Input/子 Widget/配置资产 → 引用它们的 Widget 或 DataAsset → HUD/Presenter 初始化 → Request 与结果接线 → 验收。A 的默认值引用 B，就先创建并编译 B，不让用户选择尚不存在的类。

每个关键装配步骤给实际父类、资产位置、Designer 层级、必需/可选控件、真实 Category/默认值、初始化与解绑、成功和失败连线。输入提示读取当前映射，不把示例 W/E 键当固定绑定。先完成最小闭环，再讲高级变体。

API 记录真实签名/反射/模块和调用契约；Tutorial 记录创建与连线；README 记录目的和边界。提案标为尚未实现，不写成可搜索节点。验证时从空白前置状态走教程，检查每一步所引用的对象在此前已存在；只有文本审查时不能宣称蓝图已编译或多人通过。
