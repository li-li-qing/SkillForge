# 新武器动画：实施顺序与交付门禁

在已使用 LGF + GASP/Mover 的项目增加武器、迁移动画或复核多轮交付时读取。具体故障查 [武器动画诊断](weapon-animation-diagnostics.md)，数据架构查 [跨层集成](gasp-mover-integration.md)，附件/攻击生命周期查 [装备与能力](equipment-ability-lifecycle.md)。本页补实施顺序，不另建项目状态表。

## 先明确玩家可见目标与当前基线

“装备即可使用该武器动画”表示有合格素材的状态应及时接入，不表示每个缺素材状态都强塞 Idle，也不表示把包里所有攻击/死亡送进移动数据库。

对实际玩家链记录：Source/Visible Mesh、Skeleton、Pawn 父类、Mover 关键组件、主 ABP、实际 Chooser、状态枚举、PSD/PSS、Slot/组、Retargeter。优先用官方调试实例和编辑器导出；查未使用的示例分支只能当比较资料。

保存本轮引用与文件版本，不动用户校准、第三方原件及无关武器。原来单剑正常的路径必须留作比较，不能只看新武器截图。

## 1. 素材覆盖表先于批量生成

按下列列头建立本轮小表，路径与属性从当前资产读取：

`状态 | 步态/方向 | 源片段及骨架 | 身体/Root时长与周期 | Phase/Loop | 目标候选 | 回退 | 验证`

至少覆盖本轮真正涉及的 Idle、蹲伏 Idle、Walk/Run/Sprint、起停、转向/Refacing，以及空中/Traversal 边界。缺素材写明回退，不凭 F/B/L/R 文件名认定动作方向。锁定慢走与默认跑动分开；Ctrl 的真实映射需要检查。

静态通过后才生成对应项目派生：保留搜索所需根轨迹，核对骨骼/根周期、Phase、曲线和 Notify；派生保持来源记录。已有重定向结果合格就复用，不从错误派生连续再转码。

## 2. 先接选择，再证明实际播放

保持当前 GASP 状态/Chooser 机制。根据相容搜索特征复用 PSS，候选分组按实际状态语义，不按“每方向必须一张 PSD”机械增库。

每个插入行都核对：原匹配条件、枚举值与掩码、镜像、风格容器绑定、输出与优先级；保留其他行原输出和空手/其他风格回退。Setup、Verify、Gate 共用同一份严格契约，禁止写入侧容忍坏 Root/Loop 而验证侧才拒绝。

不能默认“镜像每张表 row 0”就覆盖持续移动。先用目标上下文求值，定位 GASP 在该状态实际命中的行，再决定扩展对象。某行可能只服务过渡；给它随意增加一个枚举 bit，可能改变原语义或与前行遮蔽。检查完整条件真值表、结果类型与优先级，拒绝缺列、同名但绑定到外来对象、重复绑定及永远为假的镜像条件。

实际测试至少包含支持方向命中、无风格/其他武器回退、不支持状态回退，且从原输入驱动观察真实动画和播放时间。只构造 Chooser Context 返回预期资产是静态选择测试，不能关闭“跑三秒才切换”的运行故障。

原地装备/换风格要检查既有选择缓存失效；持续移动还要检查方向/步态变化的更新路径。不要只在 OnStateEntry 写数据，也不要每帧重启同一片段造成卡顿。短 Start 的退出提前量须小于合理有效区间，检查无候选回退是否实际可达。

## 3. 分层、移动消费与附件分别接

全身武器移动已覆盖双臂时，按实际姿态遮罩抑制静态层；先证明基础动画正确，再做握持/手指人工细调，避免用插槽掩盖姿势问题。保留脚部、Steering、Orientation/Stride Warping、Offset Root 与 Slot 的原处理顺序。

Sprint 不仅是选片：核对输入、风格许可、体力、服务器限速、Mover Modifier 与动画 Gait。允许 Sprint 时旧限速 Handle 是否已取消，不允许时才按合同限制；不能改 AnimBP 数字冒充真实移速修改。硬锁朝向映射既有 Strafe，不新建第二套 Actor 旋转真值。

双剑两部件、单剑回归、拔收刀、失败清理和远端重建先可观测。新模型换上后重新检查权威 Trace 端点；旧模型有 Socket 不代表新 StaticMesh 自动继承。

## 4. 攻击分两次交付

**完整无伤害预览**：真实 Request/Ability 路径播放完整源片段，核对骨架、实际全身 Slot、Root 消费、播放/停止和中断；报告位移只是观察，不当作批准的逐击推进。

**正式连击**：人工逐击审核后才确定 Section 边界与稳定段身份、命中/输入缓存/续招/可行动窗口、推进区间和拔收刀交接。完整连续动作优先保持连续时间轴；不要平均切五段，不以“素材叫 Attack01_5”推断五次相同窗口。

推进调整保留完整曲线，测试跨区间提取、Section 跳转、提前结束、受击取消与 Mover 重模拟；局部到世界只转换一次。锁定吸附须服务器目标校验和受限 Warp。检查同窗口双刃去重与不同挥击独立命中；不能用客户端 Notify 决定伤害。

## 5. 生成器也属于交付

修资产同时修产生错误的生成器。参数互斥在任何加载/写入前判定；错误不得留半套修改。目标白名单、来源/版本门禁、幂等、恢复及重新加载都应可验证。

一个可复现门禁至少区分：生成/修改数量、NO CHANGES、保存结果、重新加载后的属性、失败断言及退出码。诊断缺关键属性应明确报错/不支持，不静默跳过。逐场景错误计数在求值之前取基线，避免求值后采样导致增量永远为零。

副本负测由官方 duplicate/save/reload/delete 完成，重绑变更的 BranchIn 身份；恢复后新进程验证。自己的只读报告路径可配置、唯一命名，不能覆盖前序证据。索引重建与正式资产字节变动不混为一谈。

资产操作优先用当前官方公开接口；先查访问级别和导出方法，不能因 Python 某属性不可写就直接改二进制或给运行模块暴露内部数组。工具报找不到路径时先确认实际插件目录与命令传参，尤其 Git Bash 会改写 `/Game/` 参数；不能将路径改写造成的失败登记为资产损坏。

## 6. 给人工测试的交接必须可操作

只列本轮已解锁范围，不要求用户替 AI 排查仍能自动复现的错误。交接提供：实际地图/角色/武器入口、按键、准确编辑资产与字段、预览动画、保存和重装备/重启要求、预期结果及异常时要观察的数据。

推荐分开记录这些维度：

| 维度 | 证据 |
|---|---|
| 静态 | 骨架/引用、PSS、PSD 索引、曲线、Slot、窗口配置 |
| 无头逻辑 | 原输入到状态/选择/实际播放时间；切换、中断和恢复 |
| 人工视觉 | 起停/循环衔接、转向、脚滑、双手/手指、穿模、位移观感 |
| 真实联网 | Authority/owner/旁观者，Listen/Dedicated、JIP、延迟丢包下复制与清理 |
| 正式战斗 | 服务器实际命中/击空、伤害、双刃去重、受击取消及重模拟副作用 |

每一维写通过的准确范围或未执行。网络配置实值与连接观测分开；同进程 PIE、外部进程与发行包不可互代。旧回归绿不抵消当前 Trace 失败，也不把全局目标“A 已审”写成 A/B/C/D 全通过。
