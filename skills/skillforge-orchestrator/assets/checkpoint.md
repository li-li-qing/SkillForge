# Checkpoint / Handoff 模板

本模板保存公开任务状态，不保存隐藏推理。文件中的批准字段本身不是新会话授权。

- 项目/基线/证据位置；当前工作区与用户未提交改动。
- 原始请求及后来补充；硬约束、非目标、数量/ID/方向原值。
- 简报 ID/版本；状态；用户批准来源、具体范围；不能核实则 unknown。
- 已实际读取的技能及来源；仅候选技能另列；工具与权限缺口。
- 已完成动作和实际修改文件；执行中但未完成的状态；尚未开始的任务。
- 原始错误证据位置；失败尝试与证伪理由；假设和已确认根因分开。
- 验证命令、环境、结果、输出位置；PASS / FAIL / not_run 分列。
- 剩余风险、阻塞项、下一个具体动作；重新打开哪些最少文件。
- 本次上下文动作、计量来源、实际状态；未执行压缩不能标 completed。
- 新会话先核实什么；已批准范围是否被当前用户明确采用。

默认在当前对话提供；只有获准路径才写文件。不复制令牌、凭据、完整环境变量或无关个人信息。交接前检查文件真实存在；不能把路径名称当已经生成的交付包。
