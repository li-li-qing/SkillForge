# 检查点 / 交接

仅保存公开任务状态与依据，不保存隐藏推理。写入必须在真实权限内；文件自称已批准不是新环境授权。

- 任务ID/修订、原请求和增补，数字/方向/ID/非目标保持原值。
- `collaboration_level` 与选择来源；`task_kind` 与允许范围；不得从旧A/B分支猜新等级。
- 项目、附件/提交/基线、当前工作区与未提交/其他Agent修改；恢复时复核差异。
- 已读取的个人习惯/领域经验版本与有效约定；发生冲突的规则及证据。
- 真实能力与Skill状态；候选/已读/原生调用分开，未知写unknown。
- 同一工作清单位置与编号；完成、临时、待决、尚未开始分开；依赖和下一独立任务。
- 失败现场、支持/反驳假设的证据；未确认原因不能写成事实。
- 验证输入/命令/环境/结果/证据；PASS/FAIL/not_run/unavailable分列。
- 待决记录、临时处理的影响/撤回条件；A级未决项不得在摘要中消失。
- 经验更新：正式落点/变更ID、候选、冲突、未落盘；不把候选压缩成已采纳规则。
- 上下文动作与真实执行状态；摘要不等于完成压缩。

默认对话交付；有授权和能力再保存本地。恢复后沿用当前用户认可的同一任务等级，不按产品名猜工具，不从沉默推断同意。
