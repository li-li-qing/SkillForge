# Checkpoint / Handoff 模板

保存可恢复的公开任务状态，不保存隐藏推理；文件中的 approved 字段本身不是新环境授权。

- 项目 / 基线 / 证据位置；当前工作区与用户未提交改动。
- 原始请求及增补；硬约束、非目标、数量/ID/方向原值。
- 简报 ID / 版本 / 状态；批准来源与具体范围；不可核实写 unknown。
- Capability Snapshot：与恢复有关的发现、加载、读写、命令、上下文和交付能力。
- Skill：候选、可发现、已读取、已调用分别记录；不可观察写 unknown。
- 已完成动作和实际修改文件；未完成状态；尚未开始任务。
- 工作清单位置与版本、当前阶段、本批稳定编号、已回填证据、拆分/取消替代关系；下一批依赖满足项。引用同一台账，不把全部任务再复制到交接中。
- 原始错误证据；失败尝试与证伪理由；假设和已确认根因分开。
- 验证命令/方法、环境、结果、输出位置；PASS / FAIL / not_run 分列。
- 上下文 action、evidence、execution_status；没真正压缩不能写 completed。
- 剩余风险、阻塞项、下一步；恢复时最少重读哪些文件。

默认在对话输出；只有当前任务允许写文件时才持久化。不要复制凭据、令牌、完整环境变量或无关个人信息。新环境必须重新核实基线和能力。
