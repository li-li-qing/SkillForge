## 阶段：填写目标

### 大模块：填写职责

#### 子模块：填写独立能力

- [ ] **WK-0001｜填写可执行的任务名称**
  - 状态：待做 / 进行中 / 阻塞 / 完成 / 取消。
  - 归属与类型：实际责任方；设计 / 新增 / 补齐 / 接入 / 验证。
  - 优先级与交付阶段：按当前项目含义填写，区分首个闭环和后续扩展。
  - 依赖：稳定编号；无则明确写无。
  - 落点：真实文件、符号或资产；拟新增入口必须标注。
  - 动作与产出：具体改变哪个行为，交付什么，不重复标题。
  - 验收：输入/触发条件 → 可观察预期 → 检查方法。
  - 覆盖：本条适用维度、复用验收编号、不适用原因。
  - 证据：未执行；完成后填实际文件/版本、环境、命令/步骤、预期与实际、记录位置。
  - 阻塞：无，或具体外部条件、负责方与恢复条件。
  - 替代关系：仅在拆分/取消时填原项、子项及受影响后继。

## 修订与交付检查

- 原编号与完成证据保留；新号连续追加；取消与替代可追溯。
- 依赖有效无环、无取消依赖、阶段合理、引用存在、字段实填。
- 语义去重与范围覆盖通过审查；不按任务总数判定完整。
- 写明实际检查结果与未执行部分；不自动提交或创建后续目标。
