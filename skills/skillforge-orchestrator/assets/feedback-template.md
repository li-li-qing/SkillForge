# Orchestrator 试用反馈

请保留原始提示词和实际输出，敏感信息先脱敏。不是每项都必填；最少提供前四项。

1. 宿主/版本与能看到的模型标识；不可见写 unknown。
2. 项目/任务原始提示词与入口调用方式。
3. 入口实际返回的完整简报和选择的 Skill。
4. 不符合预期的位置：错误路由、额外加载、改写丢约束、重复确认、未确认执行、假压缩、漏验证。
5. 是否已有待确认/已批准简报；用户随后具体回复。
6. 实际工具轨迹与发生的写操作；是否真的读了所选 Skill。
7. 当时能读取的项目指令、技能清单、版本和上下文计量证据。
8. 你预期的正确行为；哪些现有行为需要保留。

维护者追加：复现编号、归属 routing/context/approval/prompt、最小修复、回归结果、仍未验证的宿主。
