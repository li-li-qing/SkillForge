# Orchestrator 跨宿主试用反馈

敏感信息先脱敏。最少提供前四项：

1. 宿主/版本（可选）以及**实际可观察 Capability Snapshot**；产品名不是主要判定依据。
2. 项目/任务原始提示词，以及你如何让宿主读取/选择 Orchestrator。
3. 入口实际返回的完整简报、技能集合与状态词。
4. 不符合预期的位置：错误路由、额外加载、丢约束、重复确认、未确认执行、假压缩、漏验证、错误能力假设。
5. 用户随后具体回复；是否已有 pending/approved 简报。
6. 实际工具轨迹与写操作；能否确认叶子 Skill 真正被读取/调用。
7. 当时可见的项目指令、Skill 元数据、版本与上下文证据。
8. 你预期的正确行为，以及希望保留的当前行为。

维护者追加：归属 routing/context/approval/prompt/portability；最小修复；回归结果；仍未验证的环境。
