# 待决与临时处理记录

一项一个稳定ID，可并入现有台账；不要建立第二套任务状态。

| 字段 | 内容 |
|---|---|
| 身份 | ID、任务、等级、当前版本、状态：临时/待决/已决定/已验证 |
| 问题 | 真实场景、缺失信息、影响的依赖和不受影响工作 |
| 依据 | 工程事实/用户决定/假设分别标记，可定位来源 |
| 当前处理 | 已采用的可逆措施或明确未实施的部分，原因及成本 |
| 取舍 | 有意义的选项、适用场景、利弊、推荐及不确定性 |
| 复核/撤回 | 何时复核、恢复条件、谁需要决定、具体落点 |
| 验证 | 已运行结果、证据位置、not_run及原因 |
| 后续 | 决定来源、必要测试、是否形成可复用经验 |

没有答案不是同意；没有运行证据不是通过；临时处理不是长期风格。
