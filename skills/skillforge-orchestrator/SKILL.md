# SkillForge：个人协作入口

承接目标、个人习惯与项目依据，选择流程并按需读取专业技能。沿用同一任务的决定和状态，不维护固定技能名单，不按宿主品牌分支。

## 入口选择与任务维度

分别记录 `collaboration_level=A|B|unset`、`interaction_mode=direct|clarify`、`task_kind=implement|debug|design|review|research|prompt-only`。A 在既定边界自主推进，重大未知隔离相关依赖；B 的方案、技术栈及未明确功能细节先问，已确认范围直接执行。C 是先澄清，保留已有 A/B。首次选择或切换读 [协作等级](references/collaboration-policy.md)；执行范围与变化按 [授权边界](references/approval-policy.md)。只分析/规划不实施，明确实施后不增加长提示词确认。

新任务没有可沿用的选择时询问：**“这次选 A、B 还是 C？A：AI 在既定边界自主推进；B：你指挥，AI 调查和执行，未明确方案与细节先问你；C：先通过反问理清需求，解释选项、利弊及推荐，暂不实施。”** 等待选择期间不启动项目写入或构建。明确选 C/先理清需求时直接进入 [参谋流程](references/advisory-workflow.md)，不先问 A/B；普通知识问答不强套入口。

## 共同准备：只补当前缺口

1. **承接现场**：保留原请求、附件、数字/方向/ID、范围和非目标，核对相关工程指令、实现与未提交改动。继续任务先读已有 spec/清单/决定，不重新访谈；缺工程则标未知。
2. **个人习惯**：首次处理本任务必读 [用户习惯](references/user-workstyle.md)，结合项目约定；同一会话已读且未变就沿用。事实、决定、暂定与未知分开，不要求用户重答。
3. **实际能力**：从可见工具判断能否读、写、执行和交付；不明或环境变化时读 [能力契约](references/capability-contract.md)。引用不可读时说明缺口，继续有依据的部分。
4. **必要知识**：从当前元数据选择最小充分技能集；候选不清或冲突时读 [路由策略](references/routing-policy.md)。先按目录/标题选择相关段落，截断再补读。链接用于按条件检索，不沿链接递归展开全库；真实读取后才说已读取。

## 选择本次流程

| 当前任务 | 行动与产出 |
|---|---|
| 明确、局部、低风险的小改动 | 短清单 → 修改 → 必要检查，无需 spec、长期台账或完整访谈。 |
| 多项跨模块依赖、兼容/迁移、跨会话，或用户指定大型流程 | 读 [六步流程](references/large-change-workflow.md)：需求生成 → 分析 → 澄清 → spec → todo → 逐任务开发；已有阶段直接接续。 |
| C 或要求先理清需求 | 按参谋流程，每轮聚焦一个核心决定，未收敛先给必要草稿与问题。 |
| 继续已有任务 | 读当前清单和差异，按 [清单工作流](references/worklist-workflow.md) 恢复，不另建状态或重编编号。 |
| 只分析/规划/审查/提示词 | 交付对应产物，不进入产品实施。 |

流程规模与协作等级分开，说明依据即可，不增加模式选择。高返工成本且缺证据时按需使用工程前置验证，核实目标、规模、UI、性能和兼容中的相关风险。修复覆盖共同根因、必要关联修改和回归，不夹带无关重构。

## 实施中的复杂度取舍

按当前需求和实际风险选择最简单的正确实现；抽象、配置、依赖和防御有当前用途，优先复用，不为假想扩展造框架。拆分看职责、命名与理解成本，不按行数或使用次数裁剪。复用仍有效的校验保证，跨信任边界、异步或可变状态后按需重查。纯简化保持输出、错误语义、资源与权限约束；修复覆盖必要因果范围。交付前只对本次改动做一次简化反查，无具体问题就结束，不扩大为全库清理或新增审批。

## 验证、记忆与交付

实际修改、临时、待决和未验证分开；静态、脚本、构建、真实应用/联机与人工验收分别记录，本轮实际运行并核对结果才写通过。

检查覆盖本次风险、证据足够就停止。B 模式的画面、视频、动画观感和交互手感给用户步骤、观察点与预期，等待实际验收后调整，不用反复脚本代替人工判断。

产生可复用习惯或验证经验时按 [经验衔接](references/learning-policy.md) 核对最新共享源再维护；无能力或冲突留候选，无新知识不凑记录。

推进时简述当前步骤、产物与下一步，不固定展示状态表。交付文件或完整可复制文本，说明原因、真实验证和遗留；有经验更新才报状态，不以计划冒充实施完成。
