# 维护入口与自动索引

维护时才读取，不在每次普通任务加载全部参考与测试。

## 索引不是第二份知识库

候选快照位于 [skill-index.json](../generated/skill-index.json)。条目仅含名称、原始 description、逻辑根标签、根内相对路径、可选 revision 和 SKILL.md 的 SHA-256。没有绝对路径、原始正文、凭据、安装状态或授权状态。

SHA-256 只标识入口文件字节，不证明 references/脚本未变，也不是可信签名。默认全库索引不包含入口自身，以避免递归与自引用指纹循环。新技能不需要手改白名单，但必须重建快照或使用实时清单。

## 可选工具

从本参考文件所在目录运行 `python -B ../scripts/build_skill_index.py --help` 查看参数；从技能根使用 README 中的命令。默认扫描该技能的兄弟目录并只输出 JSON，不修改文件。也可重复传入 `--root label=directory` 指定全局/项目根；路径含空格时引号包住完整参数。

`--check` 后接现有索引文件，返回 0 表示匹配、1 表示过期、2 表示输入/解析/访问错误；不写文件。`--output` 后接目标 JSON 才写文件，需先获得维护授权，且父目录必须已存在。不要把维护写入命令放进每次任务的准备阶段。

默认扫描只看直接子目录，不递归项目、缓存或用户主目录。重复技能名/根标签、链接目录、非法头部会使整次构建失败，已有索引保留。符号链接或 Windows reparse point 安装请改用宿主清单或明确的实际目录；不自动绕开边界。

只支持本库受限 frontmatter：单行 name、JSON 引号 description，可选引号字符串 compatibility/license/allowed-tools，及字符串 metadata。不是通用 YAML 解析器；未知字段、块文本、别名等会报错，不静默截短。其他生态技能先用宿主清单读取，不能未获授权修改其格式。

默认读取上限每入口 1 MiB，防止错误对象无限读入；该上限是工具保护，不是 Skill 格式标准。默认 stdout 和 check 模式适合经审阅的只读发现；output 是写操作。脚本不执行项目代码、不联网、不安装依赖、不选择模型或技能。

## 后续经验如何进入技能库

路由错误进 routing 用例；假压缩进 context 用例；重复确认或未确认写入进 approval 用例；提示词范围漂移进 behavior 用例。先保存原输入、实际工具轨迹、实际输出，再修改最小规则；新 ID 从同前缀最大编号递增，不覆盖历史证据。

业务规则进入对应专业技能，只有跨项目流程错误才写进入口。不要为一次失败把所有专业 SKILL.md 合并进来，也不要通过不断增加强制技能数量“提高可靠性”。

[反馈模板](../assets/feedback-template.md)与[评测说明](../evals/README.md)用于实测；静态规则覆盖、索引单测和实际 Agent 行为必须分开报告。
