## CPP-K03：把指数插值当"多少秒"用

| 字段 | 内容 |
|---|---|
| 状态 | 已复现（表现为"设定 1.5 秒淡出，实际约 14 秒才消失"） |
| 症状与触发条件 | 用 `FInterpTo` / `VInterpTo` 实现"在 N 秒内淡出/移动到位"，并以 `值 <= KINDA_SMALL_NUMBER` 作为完成判据 |
| 版本 | UE 5.7，`Math/UnrealMathUtility.h` 系插值函数；语义与版本无关 |
| 证据 | 指数插值每帧只走 `dt × InterpSpeed` 的剩余量；从 1.0 衰减到 `KINDA_SMALL_NUMBER` 所需秒数约为 `ln(1e4)` 除以 `InterpSpeed`，按 1.5 秒的设定推导约 13.8 秒，且位置永远只是趋近 |
| 原因 | 该族函数的参数是"趋近速度"，不是"完成时长"；把它当时长用，再叠加阈值判据，误差被放大成可感知故障 |
| 修复方向 | 需要"精确 N 秒到位"时用等速插值 `FInterpConstantTo` / `VInterpConstantTo`，速率取"全程长度除以目标时长"。**速率必须基于固定的全程长度**：用"当前剩余距离"推导速率会重新变成指数衰减，等于没修 |
| 验证结果 | 改为等速后按设定秒数到位并触发后续动作；未覆盖：不同帧率与 `DeltaSeconds` 钳制下的表现，需在低帧/卡顿场景回归 |
