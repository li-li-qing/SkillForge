# 官方资产操作、UMG 几何与预览诊断

优先使用实际版本的编辑器、Python Editor API、Data Validation、动画编辑器、IK Retargeter、官方 Animation Modifier/Phase 工具和已维护 Commandlet。没有缺口就不自建另一套编辑器或解析器；工具可用性与用户授权分别确认。

## 资产读写证据

外部解析器可以索引线索，不能只凭 raw 字节解释反射枚举或缺省属性。对可疑值使用 UE 正式加载的 get_editor_property/反射与版本源码交叉核对。编辑器持有文件时先复制到隔离读取位置；复制成功不等于副本反映未保存的编辑器改动。

修改前明确精确资产白名单和备份。第三方源默认保留，用官方 duplicate 创建项目派生；写后编译/保存、关闭进程后重新加载。保存成功、编译成功和运行行为是不同断言。破坏性验证仅在隔离副本，删除用官方资产 API 并确认引用和残留，不直接递归删除 Content。

比较蓝图导出时按对象路径和真实属性/引脚关系比较；文本重排不自动等于语义变化。GUID 只在证明对应关系后规范化，不能把全部 GUID/连线删掉再宣称图相同。导出文件可能为 UTF-16，先检查编码。

官方动画复制可能改变 Notify 对象身份；需要依赖它的数据库重绑。编辑器 Modifier 回滚缓存可能留住隔离资产；只有证实是自己测试副本的缓存时才处理该副本，不能清掉正式素材的修改历史。

## UMG 根层与生成器

一个 UE 5.7 案例的外部解析结果 0 被误读为 EStretch::None，官方加载其实是 ScaleToFitX。不能把解析器字节值直接对应头文件枚举，更不能据此重建整套 WBP。

检查正式 WidgetTree、Slot 的 Parent/Content、ScaleBox Stretch/Direction、SizeBox 的 Override 开关与实际 Desired/Allotted Size。简化 hierarchy 输出可能漏子控件；不同 UserWidget 内部树与普通 Panel 嵌套不是同一边界。

若项目约定 WBP 为布局真值，既有资产的生成命令只做获准的根层修复：保留子控件坐标、锚点、样式和绑定。检查“根已经是 ScaleBox 就跳过”的幂等门是否漏修坏属性；同时防止 -Apply 无条件重写全部页面。部分树异常应明确拒绝，首次生成和既有资产修复分别测试。

固定设计分辨率只是该项目的布局模式，不强制所有界面使用 1920×1080。缩放测试应验证实际视口与子控件绝对几何、可点击区域和文字可读性，不能只验证 UIScale 配置值。ScaleToFit 的适配可能抵消上层应用缩放；最终数值不变时保持未解决，不能用简单乘法猜原因。

## NullRHI 几何陷阱

UE 5.7 的 Slate.SkipWidgetDrawingInHeadlessMode 默认可能跳过布局所需过程，控件零几何不一定是产品坏了。核对本地 Slate 实现；诊断可临时调整官方 CVar，不永久改项目配置，也不删除尺寸断言。

FSceneViewport::ResizeFrame 在特定 PIE 路径不执行请求。使用实际支持的窗口接口后仍实测客户端视口尺寸，区分窗口外框、装饰区、客户区与 DPI。无头几何通过不等于有渲染视觉、真实鼠标拖窗或全页面可访问性通过。

## 官方预览先行

武器校准用 Skeleton/Mesh 的子 Socket + Preview Asset，不旋转 hand 骨骼。核对 Skeleton 兼容性；源 Skeleton 动画不能假定直接预览在另一 Skeleton，需正确重定向/预览场景。预览显示正确后还要核对运行附件父组件、Socket、额外偏移与实例是否刷新。

SceneCapture 预览沿输入 → 旋转目标 → 捕获相机/ShowOnly → RenderTarget → Image 排障。只转要展示的模型，避免相机/房间一起转；ChildActor 的可见图元需按实际捕获列表核对。雾和主世界光照是条件，不把隐藏到某个固定地下坐标写成通用方案。拖动检查鼠标捕获/释放和覆盖控件的命中语义，不能用可见性猜事件一定到达。
