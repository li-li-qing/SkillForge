# 正对照后续夹具：独立行为与代码验证

针对第三轮LGF/UI题未展示正对照的缺项，另构造明确可观察的Python同步owner/projection夹具。执行前冻结criteria-private.json；一名fork-none执行者仅读冻结v4技能和指定项目，未获评分点。题面直接要求解释空trace能否排除回调，较原题更聚焦，不能当等价旧新对照。

实际执行者先复现owner=7/displayed=0，证明挂载后set_count可更新显示而trace仍空；开启诊断并调用已知probe做正对照，随后定位“更新先于订阅、挂载未补快照”。只新增挂载后的refresh(owner.count)，日志默认关闭保留。执行者在日志开/关下验证初始和后续整数更新。原始答复及trace单独保存，trace为执行者记录而非完整宿主审计。

集成人读取最终代码后独立执行7组断言：原缺陷、空trace下实际回调、正对照、启用后的原缺陷事件、两种日志配置的整数更新以及修复事件链，全部通过。来源与产物哈希见before.json/reviewer-independent.json。

该明确夹具满足冻结验收，说明此次模型在给定可运行证据时能够展示正对照；不证明技能造成收益，不推翻原第三轮partial，也不能据此认定原缺项只由题面导致。无旧版对照、单样本、无Qt/UE/LGF、异步或竞态实测。未据此修改技能规则。
