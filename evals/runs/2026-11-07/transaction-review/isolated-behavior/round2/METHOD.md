# 第二轮执行方法

2026-11-07 UTC。按父任务继续 3 项最高价值探针：共享内容过期基线、只读逆向边界、UE 安装合同与新版摘录冲突。

- 三位执行者均 fork_turns=none，不继承协调者题库或评分上下文。
- 各执行者只收自己的 prompt/fixture 和只读 v4 技能路径；技能副本无 evals。
- 评分点预先写 criteria-private.json，不准执行者读取；不把评分点当任务提示。
- 任务所需业务约束写在题面，属于可见用户要求而非隐藏答案。
- shared-write 是真实本地文件最小修改，但并发通过已发生的他人编辑模拟，不是同时运行两个进程竞态，不能宣称锁/事务并发测试通过。
- readonly-reverse 使用协调者自写 C 程序，GCC -O0 -g 编译，目标不执行。真实静态二进制检查，不等于 IDA/CE 运行测试，也不是未知第三方软件。
- UE 场景显式标注合成工具合同和事实，执行仅为读取后方案/判断行为，不宣称真实 UE/MCP 连通或版本测试。
- 三者共同使用宿主系统规则和工具；允许范围靠任务约束，不是 OS 沙箱。trace 是执行者记录的过程，不是完整独立宿主审计。
- 此轮只做 v4，一题一次，不报告新旧收益或完整盲评。执行成本为三次短 subagent 任务、一次可信自写 C 编译与事后工具复核；无外部代码安装、网络接入或目标执行。
