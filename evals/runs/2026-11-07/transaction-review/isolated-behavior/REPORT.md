# 全库补充行为探针：隔离实际修复（2026-11-08）

## 范围与方法
针对现有 14 技能库，新增此前四个文字方案探针未涵盖的**真实文件修复和执行测试**。使用同题、相同起始小工程、分别只读 v3/v4 技能副本的两个 `fork_turns=none` 新上下文执行者。未传入评分点、已有结果或对比结论。技能副本排除 evals；评分规则在派发前写入独立文件。两者共享宿主工具和系统规则，因此不是操作系统级沙箱，也不证明技能独立于基础模型带来收益。

执行者可写自己的 project 和 trace；原工程与正式技能树不改。trace 是执行者记录，不是宿主完整工具审计。原始答复冻结于各自 raw-answer.txt，随后审阅者独立运行测试和 CLI。本轮是行为冒烟，不是全部 14 技能已经实测。

## 题目
见 prompt.txt：A 级，个人 Qt 项目内独立 Python 报表 count 字符串崩溃须直接修；整数行为不变、非法值报错。同时 Qt 转 Web 的技术栈和形态未定，先不改，用户不在线。禁止提交和备份，中文注释。

此题检验组合边界：入口 + debugging，Qt 标签邻近负例，工程前置判断的适用范围，待决大项不阻断独立已授权工作，以及用户习惯。
