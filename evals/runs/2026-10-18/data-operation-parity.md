# 数据操作与批量入口配对

## 范围与依据

2026-10-18 用户明确要求：管理数据要检查增删改查；全选必须配取消全选；批量添加必须配批量删除/移除，内置库导入也算批量添加。实际反馈来自状态追踪整组导入后缺少全部取消入口。本轮修改技能，不修改产品代码。

通用规则归入 UI 技能的主入口及交互参考；ArcheRage 主入口和状态追踪参考保留独立可用的领域要求。区分选择状态与业务数据、只读目录与用户关系，说明过滤/分页范围、失败恢复、持久化与无关配置保持。

## 实际行为评测

使用两个独立、无历史 fork 的只读子代理，继承相同父模型设置；精确后端版本未单独暴露。两次都未提供 expectations/rubric，只读取指定技能及按需引用，不运行产品。各一个样本，不能据此宣称普遍正确率或严格受控因果效果；第二次额外执行领域题，领域题没有独立基线。评审者为本次主代理。

通用题输入相同：开发规则订阅配置页，内置500条规则，支持整组导入、搜索、标签筛选、逐条开关/编辑，用户可能导入错组，要求完整交互方案。基线用修改前 UI 技能；正向用本次修改后技能。对应 UI-10。

| 检查点 | 修改前样本 | 修改后样本 |
|---|---|---|
| 只读库与用户集合分离，覆盖用户数据管理入口 | 满足：目录只读，订阅/参数独立，可编辑/移除 | 满足：查看、编辑、启停、退订和导入均明确 |
| 全选与取消全选配对，范围明确，取消选择不删业务数据 | 缺失：有勾选/批量移除，但未给出全选及取消全选配对 | 满足：明确三种范围及取消选择不退订 |
| 整组导入对应批量移除，能管理已保存数据 | 满足：支持选中项/筛选结果批量移除，另有批次撤销 | 满足：按组/所选批量退订，重开后仍可用 |
| 命令/持久化/失败/筛选分页/无关数据验证 | 满足：明确数据职责、失败与重开；分页细节较少 | 满足：统一命令、一次保存、筛选跨页和关闭重开 |

基线不是完全不会批量删除；本次观察到的缺口是未明确全选/取消全选配对。修改后样本补全此项，未把已有能力归功于新增规则。

领域题 AR-61：一键导入状态追踪后只想保留少数项，存在搜索、分页、当前未出现的ID、旧Auto和技能CD，HUD布局不能丢。正向样本覆盖批量/全部取消、完整已保存集合、Commands/事务、HUD/分类/库/观察记录保留、失败回滚/冷加载/实机边界，4项均满足。UI-11“取消选择不等于删除数据”新增为后续评测题，本轮未独立执行。

## 原始回答留存

### 修改前通用题

假设沿用现有配置页组件，方案如下：

- **入口**：顶部提供规则组选择与“导入”、名称搜索、标签筛选；列表显示已订阅/500、名称、标签、开关和“参数”。支持勾选后批量启用、停用、移除，明确范围为已选项或全部筛选结果。窄窗口将参数编辑收进详情页。
- **数据职责**：内置规则库只读，以稳定 ID 保存订阅、开关和参数；控件仅发出操作意图。导入显示新增、重复及冲突数量，保留已有自定义参数；记录导入批次，提供“撤销本次导入”，恢复该批次前状态。
- **失败恢复**：处理中防止重复提交；部分失败显示成功数与失败项，支持重试。参数校验失败保留草稿并定位字段；无结果提供清除筛选。
- **验证待执行**：用500条、长名称、窄窗口及高 DPI 检查布局；覆盖重复导入、选错组撤销、部分失败、重开持久化及键盘焦点恢复。

实际读取 UI 主入口、layout-patterns.md、interaction-states.md。全程只读。

### 修改后通用题

规则页方案：假设复用现有控件。页顶提供“内置库／已订阅”、名称搜索、标签筛选和整组导入；行内查看详情、启停、编辑参数及退订。内置500条规则只读，订阅关系与参数归业务层管理，UI通过统一命令提交。导入预览新增、重复和冲突数量，校验后一次保存，保留已有参数；提供即时撤销，以及重开后仍可用的按组、选中项批量退订。全选与取消全选明确区分当前页、筛选结果、全部订阅，显示数量；选择按稳定ID跨页保持，取消选择不退订。参数编辑支持保存、取消及错误定位；空结果可清除筛选，处理中防重复提交。保存失败保留上下文供重试，保存成功但刷新失败分别提示。验收覆盖误导组后批量移除、重复导入、筛选翻页外条目、失败恢复、关闭重开、键盘焦点与500条列表滚动；以上为待执行方案。

### 修改后领域题

状态追踪方案：补“已追踪”管理入口、全选／同范围取消全选、反选、批量取消及全部取消追踪，方便仅保留少数项；范围和数量显式显示。“全部”遍历持久集合，覆盖搜索、分页外、当前未出现的ID，以及自己／目标、Buff／Debuff／历史Auto和技能CD。沿用Commands与保存事务，只移除追踪关系，保留内置库、分类和导入元数据、观察记录及HUD布局颜色。验收整组导入后跨页保留几项、保存失败回滚、HUD即时移除、冷加载和插件更新不加回、无关配置一致；离线通过仍须RU实机验收。

修改后实际读取 UI 主入口与 interaction-states.md、ArcheRage 主入口与 status-tracking-contracts.md。仅只读，不修改产品或技能。
